# Nhyiraba Hotel — All Reports Luxury Design Specification

## 🎯 Overview

All PDF reports have been redesigned to match world-class luxury hotel standards comparable to Marriott International and Four Seasons Hotels & Resorts. Each report features:

- **Luxury Cover Page** with navy background, gold borders, and hotel watermark
- **Professional Headers & Footers** on all pages
- **Executive KPI Cards** with color-coded metrics
- **Professional Tables** with navy headers and alternating rows
- **Premium Typography** (Times Bold + Helvetica)
- **Consistent Color Scheme** (Navy + Gold + Accent Colors)

- Navy (Text): #0F172A (15, 23, 42)
- Gold (Borders): #D97706 (217, 119, 6)
- White (Background): #FFFFFF (255, 255, 255)
- Light Gray (Alternating Rows): #F8FAFC (248, 250, 252)

### Typography

**Cover Page**:
- Hotel Name: Times Bold, 32px, White
- Report Title: Times Bold, 26-28px, Accent Color
- Subtitle: Helvetica, 12px, Light Slate

**Body Content**:
- Section Titles: Times Bold, 18-20px, Navy
- KPI Labels: Helvetica Bold, 7px, Slate
- KPI Values: Helvetica Bold, 15px, Navy
- Table Headers: Helvetica Bold, 9px, White on Navy
- Table Body: Helvetica, 10px, Navy
- Footer Text: Helvetica, 7px, Slate

### Spacing

- Page Margins: 20px (left/right)
- Section Spacing: 20-25px
- Card Padding: 10px
- Table Cell Padding: 5-6px

- KPI Card Spacing: 15px

## 🚀 USAGE

### Generate Any Report

1. Navigate to **Reports** page
2. Select **Report Type**:
   - Executive Summary
   - Financial
   - Occupancy Insights
   - Guest Experience
   - Operational Excellence
   - Monthly Performance
3. Choose **Date Range** (7 days, 30 days, 90 days, 12 months)
4. Click **Generate PDF Report**
5. **Preview** the luxury report
6. **Download** or **Share**

### Report Features

- **Automatic Calculations**: All metrics calculated from real data
- **Professional Formatting**: World-class table and chart styling
- **Confidential Branding**: Security watermarks on all pages
- **Page Numbers**: Automatic pagination with "Page X of Y"
- **Contact Information**: Hotel details on every page
- **High Resolution**: Vector-based PDF for printing
